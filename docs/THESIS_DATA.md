## 五、双维度排序模型数据（核心创新点）

### 5.1 模型公式

```
综合得分 = α × 情感得分 + β × 热度得分 + γ × 时效性得分

其中:
- 情感得分 ∈ [-1, 1]，归一化到 [0, 1]
- 热度得分 = log(1 + 转发数×3 + 评论数×2 + 点赞数)
- 时效性得分 = exp(-λ × 发布小时数)

默认参数:
- α = 0.4 (情感权重)
- β = 0.4 (热度权重)  
- γ = 0.2 (时效性权重)
- λ = 0.1 (时间衰减系数)
```

### 5.2 热度计算权重

| 互动类型 | 权重 | 说明 |
|----------|------|------|
| 转发 | 3.0 | 传播影响力最大 |
| 评论 | 2.0 | 用户参与度高 |
| 点赞 | 1.0 | 基础认可 |

### 5.3 时间衰减函数

| 发布时间 | 衰减系数 | 说明 |
|----------|----------|------|
| 1小时内 | 0.90 | 最新热点 |
| 6小时内 | 0.55 | 当日热点 |
| 24小时内 | 0.09 | 近期热点 |
| 48小时内 | 0.01 | 历史内容 |

### 5.4 排序效果对比

| 排序方法 | NDCG@10 | MAP | 用户满意度 |
|----------|---------|-----|------------|
| 纯时间排序 | 0.623 | 0.584 | 65.2% |

## 十二、附录：关键代码片段

### 双维度排序核心算法

```python
def calculate_dual_score(self, item: Dict) -> float:
    """计算双维度综合得分"""
    # 情感得分归一化 [-1,1] -> [0,1]
    sentiment = (item['sentiment_score'] + 1) / 2
    
    # 热度得分
    heat = math.log(1 + 
        item['reposts_count'] * 3 + 
        item['comments_count'] * 2 + 
        item['attitudes_count']
    )
    heat_normalized = min(heat / 15, 1.0)  # 归一化
    
    # 时效性得分
    hours = (datetime.now() - item['created_at']).total_seconds() / 3600
    timeliness = math.exp(-0.1 * hours)
    
    # 综合得分
    return (
        self.config.sentiment_weight * sentiment +
        self.config.heat_weight * heat_normalized +
        self.config.timeliness_weight * timeliness
    )
```

### 混合情感分析核心算法

```python
def hybrid_analyze(self, text: str) -> Dict:
    """混合情感分析"""
    # 词典分析
    dict_result = self.dict_analyzer.analyze(text)
    
    # BERT分析
    bert_result = self.bert_analyzer.analyze(text)
    
    # 加权融合
    final_score = (
        0.3 * dict_result['score'] + 
        0.7 * bert_result['score']
    )
    
    # 确定标签
    if final_score > 0.2:
        label = 'positive'
    elif final_score < -0.2:
        label = 'negative'
    else:
        label = 'neutral'
    
    return {
        'score': final_score,
        'label': label,
        'confidence': bert_result['confidence'],
        'dict_score': dict_result['score'],
        'bert_score': bert_result['score']
    }
```
