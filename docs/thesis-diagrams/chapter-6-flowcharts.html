第六章 系统详细设计与实现流程图

以下功能设计流程图采用论文常用黑白竖向样式：开始/结束为椭圆，处理为矩形，判断为菱形，数据输入输出为平行四边形。

图6-1 数据采集模块功能设计流程图

flowchart TD
      S([开始]) --> A[进入数据采集页面]
      A --> B[/输入关键词、数量和时间范围/]
      B --> C{参数是否完整}
      C -- 否 --> D[提示补充采集参数]
      D --> B
      C -- 是 --> E[提交采集任务]
      E --> F[后端创建任务并调用爬虫]
      F --> G[保存微博数据和采集日志]
      G --> H[刷新任务进度]
      H --> T([结束])
