## 第5页：创新点1 - 双维度排序模型

### 核心公式
```
DualScore = α × 情感得分 + β × 热度得分
```

### 热度计算
```
HeatScore = 互动得分 × 时间衰减 × 用户影响力
```

### 四象限分类
[四象限图]
- 重点关注（高情感高热度）
- 潜在风险（高情感低热度）
- 热门中性（低情感高热度）
- 一般内容（低情感低热度）

## 第7页：创新点2 - 混合情感分析

### 方法对比
| 方法 | 准确率 | 速度 |
|------|--------|------|
| 词典 | 72% | 5000条/秒 |
| BERT | 89% | 50条/秒 |
| **混合** | **86%** | **200条/秒** |

### 融合策略
```
FinalScore = w₁ × 词典得分 + w₂ × BERT得分
```
- 根据置信度动态调整权重
- 平衡精度与效率

## 第8页：创新点3 - Spark优化

### 优化策略
1. **Kryo序列化**：性能提升10倍

3. **智能分区**：数据均衡分布
4. **缓存策略**：避免重复计算
