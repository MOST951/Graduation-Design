## 三、核心算法流程

### 3.1 三维度排序算法

```
输入: 微博数据列表 D = {d₁, d₂, ..., dₙ}
输出: 排序后的列表 D' 和四象限分类

算法流程:
1. FOR each d in D:
   │
   ├── 2. 情感分析
   │   ├── 词典分析 → lex_score, lex_conf
   │   ├── BERT分析 → bert_score, bert_conf
   │   └── 融合 → sentiment_score = w₁×lex + w₂×bert
   │
   ├── 3. 热度计算
   │   ├── 互动得分 = log(1 + w₁×转发 + w₂×评论 + w₃×点赞)
   │   ├── 时间衰减 = exp(-λ × Δt)
   │   ├── 影响力 = log(1 + 粉丝数) × 认证加成
   │   └── heat_score = 互动 × 衰减 × 影响力
   │
   ├── 4. 归一化
   │   ├── sentiment_norm = (sentiment_score + 1) / 2
   │   └── heat_norm = heat_score / max_heat
   │
   ├── 5. 三维度得分
   │   └── tri_score = α × sentiment_norm + β × heat_norm
   │
   └── 6. 四象限分类
       ├── IF sentiment_norm ≥ θs AND heat_norm ≥ θh → 重点关注
       ├── IF sentiment_norm ≥ θs AND heat_norm < θh → 潜在风险
       ├── IF sentiment_norm < θs AND heat_norm ≥ θh → 热门中性
       └── ELSE → 一般内容

7. 按 tri_score 降序排序
8. 返回 D' 和分类结果
```

### 3.2 混合情感分析算法

```
输入: 文本 text
输出: 情感标签 label, 得分 score, 置信度 confidence

算法流程:
1. 词典分析
   │
   ├── 分词处理
   ├── 匹配正面词 → pos_count, pos_weight
   ├── 匹配负面词 → neg_count, neg_weight
   ├── 检测否定词 → negation_flag
   ├── 检测程度词 → degree_multiplier
   │
   └── lex_score = (pos_weight - neg_weight) × degree × negation
       lex_conf = min(1.0, |lex_score| + 0.3)

2. BERT分析
   │
   ├── Tokenize → input_ids, attention_mask
   ├── 模型推理 → logits
   ├── Softmax → probabilities [neg, neu, pos]
   │
   └── bert_score = P(pos) - P(neg)
       bert_conf = max(probabilities)

3. 动态融合
   │
   ├── 计算动态权重
   │   ├── total_conf = lex_conf + bert_conf
   │   ├── w₁ = base_lex_weight × lex_conf / total_conf
   │   └── w₂ = base_bert_weight × bert_conf / total_conf
   │
   ├── 归一化权重
   │   ├── w₁ = w₁ / (w₁ + w₂)
   │   └── w₂ = w₂ / (w₁ + w₂)
   │
   └── final_score = w₁ × lex_score + w₂ × bert_score

4. 确定标签
   ├── IF final_score > 0.2 → "positive"
   ├── IF final_score < -0.2 → "negative"
   └── ELSE → "neutral"

5. 返回 label, final_score, max(lex_conf, bert_conf)
```

### 5.2 请求/响应示例

**三维度分析请求**：
```json
POST /api/tri-dimension/analyze
{
  "data": [
    {
      "id": "1",
      "text": "这个产品太棒了！",
      "reposts_count": 1000,
      "comments_count": 500,
      "attitudes_count": 5000,
      "followers_count": 100000,
      "verified": true
    }
  ],
  "config": {
    "sentiment_weight": 0.5,
    "heat_weight": 0.5
  }
}
```

**响应**：
```json
{
  "code": 200,
  "data": {
    "ranked_posts": [
      {
        "id": "1",
        "rank": 1,
        "tri_score": 0.7823,
        "sentiment": {"polarity": "positive", "score": 0.85},
        "heat": {"score": 0.68, "time_decay": 0.95},
        "quadrant": "high_sentiment_high_heat"
      }
    ],
    "quadrant_statistics": {
      "high_sentiment_high_heat": {"count": 1, "ratio": 1.0}
    }
  }
}
```
