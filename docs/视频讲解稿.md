## 一、开场介绍（约1分钟）

### 【画面：系统首页】

大家好，欢迎观看微博舆情情感分析系统的演示视频。

本系统是一个基于大数据技术栈的**实时微博舆情监控与情感分析平台**，主要用于采集微博数据、分析用户情感倾向、监控热点话题，为企业舆情管理和社会舆论研究提供数据支持。

系统采用**前后端分离架构**：
- 前端使用 **React + TypeScript + Ant Design**
- 后端使用 **Flask + PySpark**
- 深度学习模型使用 **ChineseBERT**
- 数据存储使用 **MySQL + Redis + HDFS**

下面我将从系统功能、技术架构、核心算法三个方面进行详细介绍。

### 3.2 数据流转（约1分钟）

#### 【画面：数据流图】

来看数据是如何在系统中流转的：

**1. 数据采集阶段**
```
微博API → 爬虫服务 → 原始数据 → HDFS存储
```
爬虫采集的原始数据首先存入HDFS，保证数据不丢失。

**2. 数据处理阶段**
```
HDFS原始数据 → Spark清洗 → 结构化数据 → MySQL/HBase
```
Spark对原始数据进行清洗、去重、分词，转换为结构化数据。

**3. 情感分析阶段**
```
结构化数据 → 混合分析器 → 情感标签 → 结果存储
```
混合分析器融合规则和深度学习，输出情感标签和置信度。

**4. 实时查询阶段**
```
用户请求 → Redis缓存 → MySQL查询 → 前端展示
```
热点数据缓存在Redis，保证毫秒级响应。

## 四、核心算法讲解（约2分钟）

### 4.1 情感分析算法（约1.5分钟）

#### 【画面：算法流程图】

下面重点介绍**混合情感分析算法**。

算法分为以下步骤：

**第一步：文本预处理**
```
原始文本 → 分词 → 词性标注 → 表情提取
```
使用jieba进行中文分词，同时提取表情符号。

**第二步：规则分析**
```
分词结果 → 情感词匹配 → 程度词修饰 → 否定词反转 → 规则得分
```
- 匹配情感词典中的正面/负面词
- 程度副词（非常、太）放大情感强度
- 否定词（不、没）反转情感极性
- 转折词（但是）调整权重

**第三步：BERT分析**
```
原始文本 → BERT编码 → 分类头 → 概率分布 → BERT得分
```
使用微调后的ChineseBERT模型，输出三分类概率。

**第四步：结果融合**
```
最终得分 = α × 规则得分 + β × BERT得分
```
- α和β根据文本特征动态调整
- 短文本、情感词多时，规则权重高
- 长文本、语义复杂时，BERT权重高

**第五步：置信度计算**
```
置信度 = 基础置信度 + 一致性加成
```
如果规则和BERT结果一致，置信度+10%。
